# rasweb

A React + TypeScript + Tailwind scaffold for a redesigned IEEE RAS chapter website.

## Status
Work in progress — this repo currently holds the project configuration (Vite, TypeScript, Tailwind, ESLint) but no `src/` yet. The live chapter site today is the separate [RAS](https://github.com/Mrinal-Midha/RAS) repo (plain HTML); this is the planned rebuild.

## Tech stack
React, TypeScript, Vite, Tailwind CSS.

## Getting started (once source files are added)
```bash
npm install
npm run dev
```
